\section{Checks against the repository}

\begin{itemize}
  \item \textbf{Read in full during the analysis:} every module under \code{src/vidyarag/}, \code{app/app.py}, \code{scripts/deploy_space.py}, all configuration files, \code{pyproject.toml}, the Dockerfile, the compose file, all three workflows, \code{.gitignore}, \code{.pre-commit-config.yaml}, \code{.env.example}, the Makefile, the README, the Space README, \code{docs/DESIGN.md}, and the full commit history with messages.
  \item \textbf{Read for specific facts:} \code{docs/EVALUATION.md}, \code{ATTRIBUTION.md}, the gold set and review sheet, the five run files (parsed programmatically), and the test modules (names, fixtures and selected bodies).
  \item \textbf{Executed:} the hermetic test suite with coverage; the corpus download check and a full index rebuild; traced \code{guarded} queries with wall-clock timing; a stage benchmark; the grader on a stored answer; the abstention judge reproduction and the re-judging of all stored answers; the guard patterns over the whole index and over new phrasings; the local API; the live Space.
  \item \textbf{Cross-checked:} every committed aggregate was recomputed from per-question data; the README table was compared with the run files; claims in comments and documents were compared with the code they describe.
\end{itemize}

\section{Known limitations of this report}

\begin{enumerate}
  \item \textbf{It is a snapshot} of commit \code{fa5164b}. Line numbers, and some findings, will change as the repository changes.
  \item \textbf{Some measurements are single runs on a laptop}, whose timings varied several-fold between sessions; treat them as indicative.
  \item \textbf{The corrected abstention figures come from a language-model judge}, which is not deterministic, and the \enquote{stricter reading} of partial answers is a human judgement made during this analysis.
  \item \textbf{Memory use and throughput were not measured}, and the Space's hardware could not be determined.
  \item \textbf{\code{docs/EVALUATION.md} was used for specific figures} rather than re-read line by line in the final pass; where its numbers matter, they were cross-checked against the run files or commit messages.
  \item \textbf{Diagrams are reconstructions} from the code; the repository itself contains only the Mermaid pipeline diagram.
  \item \textbf{Classification granularity}: inside a verified paragraph, a closing clause of interpretation is occasionally tagged rather than moved to its own box, for readability.
  \item \textbf{Secrets are never shown}: only the placeholder values committed in \code{.env.example} appear.
\end{enumerate}
