\chapter{Design Decisions and Trade-offs}
\label{ch:tradeoffs}

Every major design decision in VidyaRAG was a choice between alternatives with different costs. This chapter lists them in one place. The \emph{decision}, \emph{alternatives} and \emph{stated reason} columns are verified from the code, configuration comments, \code{docs/DESIGN.md} and commit messages. The \emph{cost} column says whether the cost is stated in the repository or inferred.

\begin{interview}
Choose three of these to discuss in depth, and describe each as a trade-off rather than a preference. For example: \enquote{I shipped the index inside the Space instead of using a managed vector database. It removes an expiring dependency and a network hop; the cost is exact search, fine at 3,608 chunks and not past about 20,000, where the same client factory points at a Qdrant server.}
\end{interview}
